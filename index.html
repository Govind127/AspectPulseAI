System Architecture & Methodology

How Phase 1 & 2 NLP Powers Phase 3 Predictive Analytics

Engine: src/predictive_analytics.py
PHASE 1 • DIAGNOSTIC NLP RoBERTa BIO Tagger

Aspect Term Extraction (ATE)

Scans raw unstructured customer reviews using BIO sequence tagging (B-ASP / I-ASP / O) to isolate exact hardware and service attributes such as battery life, display, and build quality.

Output: Extracted Aspect Spans [from, to]
PHASE 2 • SENTIMENT & XAI RoBERTa + Captum

Polarity & Feature Attribution

Evaluates each [Review + Aspect] pair to assign confidence-weighted polarity (+1, 0, -1) and verifies modifier words using Captum Layer Integrated Gradients.

Output: Feature Vector X = [X₁, X₂, ..., X₇]
PHASE 3 • PREDICTIVE ANALYTICS Statistical & Risk Engine

Rating, Churn Risk & Rule Mining

Transforms the 7 aspect sentiment scores (X₁…X₇) and negative dummy flags (D₁…D₇) into quantitative predictions: expected Star Rating, Logit/Probit Return Risk probability, Apriori defect rules, and sentiment trend forecasts.

Output: Ŷ (Stars), P(Return) & Defect Rules

What Phase 3 Predictive Analytics Computes (4-Module Breakdown)

Every technique maps unstructured NLP outputs into formal econometric and statistical predictive models.

Fitted on 24,265 SQLite Aspect Records
MODULE 01 • OLS REGRESSION
Multiple Linear Rating Model

Estimates Ŷ = β₀ + ΣβᵢXᵢ to measure how much each aspect's sentiment raises or lowers a 1–5 star rating, validated via t-tests and F-test.

MODULE 02 • NON-LINEAR & DIAG
Quadratic Curvature & Checks

Adds β₈ΣXᵢ² for diminishing returns and audits assumptions via VIF (multicollinearity), Breusch-Pagan, Durbin-Watson, and Shapiro-Wilk.

MODULE 03 • LOGIT & PROBIT
Binary Return-Risk Models

Uses 0/1 negative aspect dummy variables in Logistic CDF and Normal CDF (Φ(z)) models to bound product return probability strictly in [0, 1].

MODULE 04 • APRIORI & SES
Defect Rules & Trend Forecast

Mines co-occurring aspect failures (Support, Confidence, Lift) and forecasts next-period Net Sentiment using Moving Average & Exponential Smoothing.
